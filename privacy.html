Privacy Policy

Last updated: 22 November 2026

EQ Code Bridge ("the app") is a private tool used only by its owner, Ahmed Elkomy (aahmedaelkomy@gmail.com).

What the app accesses

With the owner's consent through Google sign-in, the app accesses the owner's own Google Apps Script projects, Google Sheets and Google Drive files, and the email address of the signed-in account. It may send email from the owner's account to the owner.

How the data is used

The data is used only to copy script code between the owner's Google account and the owner's GitHub repository, to deploy script versions, and to run the owner's own script functions. The app does not use the data for advertising, profiling or any other purpose.

Sharing

The app does not sell, rent or share any Google user data with third parties. Script source code is stored in the owner's own GitHub repository. No spreadsheet or Drive content is stored outside the owner's Google account.

Retention and deletion

The app keeps no separate database. Access can be removed at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
