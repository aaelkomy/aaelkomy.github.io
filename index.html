EQ Code Bridge

EQ Code Bridge is a private internal tool built and used only by Ahmed Elkomy (aahmedaelkomy@gmail.com).

It keeps the Google Apps Script projects in the owner's own Google account in sync with the owner's own GitHub repository, deploys new versions of those scripts, and runs selected script functions on the owner's own Google Sheets and Google Drive files.

The tool is not offered to the public and has no other users.
